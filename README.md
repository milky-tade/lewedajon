# LEWEDAJO — Trusted Ethiopian Diaspora Delivery Service
> **ለወዳጆ** — Safe, reliable shopping and delivery for your loved ones in Ethiopia.

LEWEDAJO bridges the gap between Ethiopian diaspora communities worldwide and their families in Ethiopia. Customers abroad can request custom shopping and delivery for medicines, groceries, gifts, electronics, and documents with end-to-end photo confirmation and receipt proof.

---

## 🌟 Key Features

- **Multilingual Support:** Full native translations in English, Amharic (አማርኛ), and Afaan Oromoo.
- **Service Categories:**
  - 💊 Medicine Delivery (Verified pharmacies with receipts)
  - 📄 Document Delivery (Confidential & secure pickup)
  - 💻 Electronics Delivery
  - 🎁 Gift Delivery & Custom Care Packages
  - 🛒 Grocery & Household Essentials
- **Proof of Delivery Section:** Real photo confirmation of purchases, packaging, delivery, and customer satisfaction.
- **Direct WhatsApp Ordering:** Instant 1-click order submission to WhatsApp (`+251 946 734 473`) with structured order details.
- **Modern Responsive Design:** Crafted with Tailwind CSS, AOS scroll animations, Font Awesome 6, and custom brand SVG icons.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with any static web server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```
